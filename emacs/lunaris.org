#+title: lunaris — the complete configuration reference
#+options: toc:t num:t

* Overview

This emacs config = is a standalone `~/.emacs.d` replacement built by nix
(`emacsWithPackagesFromUsePackage` from =emacs-overlay=). It is **based on Doom
Emacs**: presents as doom emacs — same look, same `<leader>` and bracket
keybindings, same enabled module set — without doom's module system,
straight.el, or doom core. Everything doom-specific is ported into the repo or
approximated with a vanilla equivalent. Doom's module tree lives at
=doom-modules/= (gitignored) as the porting reference.

Three-layer architecture:

| layer    | file                      | role                                       |
|----------+---------------------------+--------------------------------------------|
| boot     | =init.el=, =early-init.el= | entry, package.el off, autoloads, globals |
| backend  | =lunaris.el=              | unified framework: leaf DSL, lbind, luna-compat, manifest, tree loader |
| config   | =config/ + =framework/=   | your config (always) + doom ports (manifest toggle) |

The config side is declarative: it only calls the backend API. All machinery
lives in =lunaris.el=.

* Framework — lunaris.el (34 macros/functions)

Six subsystems.

** leaf — package declaration DSL

Own recreation of =conao3/leaf=. Wraps =use-package=; keyword names identical
so decls read like leaf:

#+begin_src emacs-lisp
(leaf vertico :ensure t :demand t :config ...)
(leaf hl-todo :hook (prog-mode . hl-todo-mode))   ; :defer implied
#+end_src

Defaults when omitted:

| default    | condition                                 |
|------------+-------------------------------------------|
| `:ensure t`| no `:ensure` given                        |
| `:defer t` | `:hook`/`:bind`/`:commands` present, no `:defer`/`:demand` |

Supported keywords: =:ensure :defer :demand :hook :bind :config :init
:custom :after :commands :when :mode :preface=.

** lbind — my own keybinding DSL

Cleaner re-imagination of doom's =map!=. Flat, keyword-first. Compiles to the
same robust emitter as =map!= (per-state, error-swallowing):

#+begin_src emacs-lisp
(lbind :leader "x" #'cmd "y" #'cmd2)      ; SPC x, SPC y
(lbind :localleader "z" #'cmd)            ; SPC m z
(lbind :prefix "gd" "n" #'cmd)            ; g d n
(lbind :map dired-mode-map "a" #'cmd)     ; mode map
(lbind "C-x x" #'cmd)                     ; raw full key
#+end_src

Keywords: =:leader :localleader :prefix :map :keymaps=. Defaults to all evil
states. Prefer =lbind= for new bindings.

** luna-compat — macros

Ported from doom-emacs so migrated module code runs near-verbatim. The compat
layer uses the =luna-= prefix (unified naming); legacy =doom-= names remain as
aliases.

| macro          | role                                                     |
|----------------+----------------------------------------------------------|
| =after!=       | runtime =eval-after-load= (compiler-safe against self-feature cycles) |
| =map!=         | doom keybinding syntax → per-state =general-def=, errors swallowed |
| =lbind=        | my DSL (above)                                           |
| =cmd! / cmds! / cmd!!= | interactive lambdas                            |
| =defadvice! =  | =(defun ...)= + =(advice-add ...)=                     |
| =modulep! =    | manifest lookup; supports bare-flag and `-flag` negation |
| =setq-hook! / add-hook! / remove-hook! = | hook helpers                    |
| =leaf=         | declaration DSL                                          |

** manifest — (lunaris! ...)

The enabled module set, doom!-style, in =manifest.el=:

#+begin_src emacs-lisp
(lunaris! :completion (corfu +orderless) (vertico +icons +childframe)
          :ui deft doom ...)
#+end_src

Parsed into =lunaris--manifest= (alist =group → ((sub flags...) ...)=). Feeds
=modulep!=.

=modulep!= semantics:

| call                          | true when                                  |
|-------------------------------+--------------------------------------------|
| =(modulep! :ui)=              | group :ui enabled                          |
| =(modulep! :ui vc-gutter)=    | submodule enabled                          |
| =(modulep! :ui vc-gutter +pretty)= | submodule + all flags               |
| =(modulep! :tools lsp -eglot)=| enabled and `eglot` flag absent            |
| =(modulep! +lsp)=             | any enabled submodule carries `+lsp` (bare flag) |

** tree loader — lunaris-stage-2

Per-group import: =framework/<group>/<group>.el= always loads first; then
every =framework/<group>/<module>.el= gated by `(modulep! :<group> <module>)`.
Chunked — 4 files per idle tick so typing never blocks; =lunaris-stage-2-now=
loads everything synchronously (tests). Modules are byte-compiled into
=~/.cache/lunatix-emacs/lisp= on first run, loaded compiled afterwards. The
cache dir is appended to =load-path= so its module copies never shadow
same-named package files (e.g. =php.el=, =latex.el=) — that caused eager
macro-expansion cycles. Errors are logged (=lunaris-log=, gated by
=lunaris-debug=), never fatal.

** doctor — module health check

`lunaris-doctor` = doom-doctor-style health check. Each group dir may ship a
=doctor.el= (loaded only by the doctor, never stage-2) whose forms gate on
`(modulep! ...)` and report via =ok! = =warn! = =error! = — missing
executables, unavailable libs. Reports group by module; =lunaris-doctor-count=
tallies for tests. =test.sh= requires ≥1 =ok! =.

** helpers

Own re-implementations (no doom-emacs at runtime), =luna-= prefix: =luna-leader-key= (SPC),
=luna-localleader-key= (SPC m), =luna-project-root=, =luna-call-process(-in)=,
=luna-region-active-p=, =luna-point-in-comment-p=, =luna-temp-buffer-p=,
=luna-fallback-buffer=, profile-dir functions, no-op =luna-*-hook= vars,
=lunaris-log= / =lunaris-debug=.

** Boot flow (=init.el=)

1. =lunatix-emacs-dir= ← dir of =init.el= (portable).
2. `evil-want-keybinding nil` before anything loads evil.
3. =config/= on load-path; =lunaris.el= loaded (whole backend).
4. =use-package=: `always-defer t`, `ensure-function` no-op (nix builds
   packages; zero network).
5. All `*-autoloads.el` loaded (nix wrapper never registers them).
6. =manifest.el= loaded → =lunaris--manifest=.
7. =config/= loads synchronously (stage 1: identity + keys + dashboard).
8. =lunaris-stage-2= loads =framework/= in the background (4 files/idle tick),
   group files first, then manifest-gated module files, byte-compiled to the
   cache.
9. Defaults: no tabs, truncate, line numbers (relative), no menu/tool/scroll
   bars, frame title = buffer name.

** nix integration

=modules/lunix/emacs/emacs.nix=: =emacs-overlay= provides
=emacsWithPackagesFromUsePackage=; =config= = =init.el= + recursive glob of
 =config/ + =framework/=  (=lib.filesystem.listFilesRecursive=) concatenated. Package
set single-sourced from `:ensure` decls. =extraEmacsPackages=: eglot, treesit
grammars, EAF composite. Home packages include LSP servers, compilers,
=nerd-fonts.jetbrains-mono=.

* Keybindings — unified scheme

Four consistent surfaces:

| surface      | prefix      | role                            |
|--------------+-------------+---------------------------------|
| leader       | =SPC=       | actions                         |
| localleader  | =SPC m=     | current major mode              |
| bracket      | =[= =]=     | navigation: prev/next           |
| goto         | =g=, =M-g=   | jump (evil + xref)              |

** Leader (SPC)

=SPC := M-x, =SPC b= buffer, =SPC c= code, =SPC e= denote, =SPC f= file,
=SPC g= git, =SPC h= help, =SPC i= insert, =SPC n= notes, =SPC o= open,
=SPC p= project, =SPC q= quit, =SPC r= remote, =SPC s= search, =SPC t= toggle,
=SPC T= workspaces, =SPC v= term, =SPC w= window (=evil-window-map=).

** Bracket ([ ])

=prev/next= across things (doom convention):

| key       | action                         |
|-----------+--------------------------------|
| =b= =B=   | buffer / buffer other window    |
| =f=       | file (recentf cycle)            |
| =d= =D=   | error / flycheck error          |
| =h=       | diff-hl hunk                    |
| =s=       | evil search match               |
| =w=       | window                          |

** Minibuffer

=[escape]= aborts in one press (bound as the symbol, not char — the GUI
gotcha that caused 3-press ESC). =C-s= consult-history. Smart =C-a/C-e=.

* Test

=test.sh= loads =init.el= with =debug-on-error t= and asserts 34 invariants
(evil, leader tree, theme, modeline, completion, magit, lsp, workspaces,
wanderlust, elfeed, circe, bars off, doctor ≥1 ok). Run:

#+begin_src bash
EMACS="$(nix build .#emacs --print-out-paths)/bin/emacs" ./test.sh
#+end_src

The doom module tree is checked out at =doom-modules/= (gitignored, reference
only) for consulting =packages.el= / =config.el= when porting or upgrading.
