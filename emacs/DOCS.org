#+title: lunatix emacs — literate reference
#+options: toc:t num:t

Standalone `~/.emacs.d` (linked to this repo). Built by nix
(`emacsWithPackagesFromUsePackage` from =emacs-overlay=). Doom-emacs look and
keys without doom's module system — the backend is `lunaris.el`, the doom ports
live in =framework/= (toggle via =manifest.el=), your config in =config/=.

One section per file. Every top-level function/macro/custom/var with its
docstring. Generated — the docstring is the source of truth; the purpose line
is editorial.
