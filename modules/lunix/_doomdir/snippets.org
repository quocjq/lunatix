#+title: Snippets
#+property: header-args :comments no

Literate source for YASnippet. Each =#+begin_src= block tangles to a
single =.yasnippet= file under =$DOOMDIR/snippets/<mode>/=. Pulled
into =config.org= via =#+INCLUDE:=, so saving =config.org= re-tangles
all of these along with the rest of the Doom config.

=:comments no= matters — yasnippet reads the file as raw text and
anything org-babel adds as wrap comments would be misinterpreted as
snippet metadata.

See =snippets-guide.org= for the snippet file format, placeholders,
and how to add new ones.

* Org-mode

** today — current date (YYYY-MM-DD)
#+begin_src snippet :tangle snippets/org-mode/today.yasnippet
# -*- mode: snippet -*-
# name: today
# key: today
# --
`(format-time-string "%Y-%m-%d")`
#+end_src

** time — current time (HH:MM)
#+begin_src snippet :tangle snippets/org-mode/time.yasnippet
# -*- mode: snippet -*-
# name: time
# key: time
# --
`(format-time-string "%H:%M")`
#+end_src

** now — current date and time
#+begin_src snippet :tangle snippets/org-mode/now.yasnippet
# -*- mode: snippet -*-
# name: now
# key: now
# --
`(format-time-string "%Y-%m-%d %H:%M")`
#+end_src

** denote-note — new note skeleton
#+begin_src snippet :tangle snippets/org-mode/denote-note.yasnippet
# -*- mode: snippet -*-
# name: denote-note
# key: denote-note
# --
#+title: $1
#+filetags: $2
#+date: `(format-time-string "%Y-%m-%d")

$0
#+end_src

#+begin_src snippet :tangle snippets/org-mode/denote-journal.yasnippet

# name: denote-journal
# key: denote-journal

#+title: `(format-time-string "%Y-%m-%d %A")`

#+date: `(format-time-string "%Y-%m-%d")

$0
#+end_src

** denote-link — insert denote-style link
#+begin_src snippet :tangle snippets/org-mode/denote-link.yasnippet
# -*- mode: snippet -*-
# name: denote-link
# key: denote-link
# --
[[denote:$1]]$0
#+end_src
